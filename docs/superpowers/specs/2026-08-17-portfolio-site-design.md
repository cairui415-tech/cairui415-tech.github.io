# 蔡睿个人作品集网站设计规格

## 目标

为互联网公司招聘场景创建一个适合 PC 端展示的单页个人作品集。网站需要在较短浏览时间内同时呈现蔡睿的内容策略、数据分析、行业研究与 AI 产品策划能力，并为后续依据参考截图进行视觉升级保留清晰、稳定的结构。

## 首版范围

- 使用 React 与 Vite 构建可本地运行、可预览的单页网站。
- 页面最大内容宽度约为 1700px，重点适配 1440px 及以上桌面屏幕，并提供基本窄屏适配。
- 包含全屏 Hero、个人经历、精选项目、个人优势、专业技能和整屏联系方式六个模块。
- 使用本地抽象动态视频作为 Hero 背景；在不支持自动播放或用户启用减少动态效果时提供静态视觉回退。
- 使用抽象人物视觉代替真实头像，后续可直接替换为用户照片。
- 项目图片使用独立、可替换的媒体槽，不将临时视觉与页面结构耦合。
- 不包含后台、复杂路由、在线联系表单、访问统计或内容管理系统。

## 信息定位与内容策略

网站将蔡睿定位为“研究驱动的复合型候选人”：能够通过数据与行业研究发现问题，并将洞察转化为内容策略和 AI 产品方案。

首页主叙事不限定单一岗位，而以四项相互关联的能力为主线：

1. 研究与洞察
2. 数据分析与可视化
3. 内容策略与传播
4. AI 产品与商业思维

内容依据简历整理，首版突出以下量化结果：

- 上观新闻账号任职期间涨粉突破 10 万
- 单条内容最高播放量突破 500 万
- 数据新闻收集 150 余份问卷
- 两篇流媒体广告研究成果发表于 ICA 2026
- 获复旦大学校级科研资助 4,000 元

## 页面结构

### 1. 全屏 Hero

- 顶部导航包含“关于我”“项目”“优势”“联系”四个锚点。
- 首屏展示姓名、复合能力定位、一句简短价值陈述和联系按钮。
- 背景为明亮、克制的抽象动态视频，并使用渐变遮罩保证文字对比度。
- 联系按钮跳转到页面底部联系模块。

### 2. 个人经历

- 左侧或上方放置抽象人物视觉，媒体容器允许后续替换真实照片。
- 展示个人介绍、复旦大学教育背景和三段实习经历。
- 展示邮箱、电话、所在城市。
- 以数据条或数据卡展示关键成果。

### 3. 精选项目

使用大尺寸项目卡展示四个代表项目：

1. 数据新闻《陷入养老焦虑的年轻人，正在寻找新出路》
2. “星芽”AI 青少年陪伴产品策划
3. AI 音频产业及 Suno/Udio 经营策略研究
4. ICA 2026 流媒体广告研究

每张卡包含项目名称、项目类型、年份、职责、成果摘要、能力标签和可替换图片区域。首版不创建虚构的外部项目链接。

### 4. 个人优势

使用四张能力卡展示：

- 研究洞察：行业研究、用户研究、实验设计与学术写作
- 数据分析：Excel、SPSS、LMM、生理数据与信息可视化
- 内容策略：账号运营、热点识别、视频内容与叙事表达
- AI 产品思维：产品策划、竞品分析、商业化与 AI 辅助工作流

### 5. 专业技能

使用技能矩阵将具体工具与应用场景分为四组，不使用主观的百分比熟练度进度条：

- AI 与效率：Claude Code、Codex、ChatGPT，AI 辅助研究、脚本创作、数据分析与快速学习
- 数据分析：Excel、SPSS、Julius AI、LMM 分析、数据清洗与可视化
- 商业与金融研究：Choice、Wind、财务指标分析、行业研究、竞品分析与 SWOT
- 用户与实验研究：MediaLab、Biopac / AcqKnowledge、Tobii Pro、问卷设计与生理数据采集

每组包含类别名称、能力优势说明和具体工具标签，帮助面试官快速匹配岗位要求。

### 6. 整屏联系方式

- 以简洁的大标题邀请招聘方联系。
- 展示邮箱和电话，并提供可点击的邮件与电话链接。
- 提供返回顶部入口。
- 保持完整视口高度，作为页面明确收尾。

## 视觉基线

首版只定义可用的视觉骨架，不锁定最终风格：

- 亮色背景，深色正文，使用单一冷色作为强调色。
- 使用大字号标题、宽松留白、细线边框和克制阴影。
- 避免常见模板式渐变玻璃卡片、过度圆角和无意义装饰。
- 动效限于首屏视频、元素进入视口时的轻量过渡及可感知的交互反馈。
- 尊重 `prefers-reduced-motion`，减少或停止非必要动态效果。

## 技术结构

- React 负责页面组件与内容渲染，Vite 负责开发与构建。
- 页面拆分为导航、Hero、个人经历、项目列表、能力列表、技能矩阵和联系方式组件。
- 简历内容与项目内容集中存放于独立数据模块，避免散落在组件中。
- 全局设计变量集中定义颜色、字体、间距、版心和动画时长，方便后续依据参考图换肤。
- 使用语义化 HTML、可见键盘焦点、有效链接标签和足够色彩对比度。
- 不依赖运行时外部接口；页面在本地静态构建后即可工作。

## 错误与回退处理

- Hero 视频加载失败时显示同色系静态背景，不影响文字和导航。
- 抽象人物图或项目图缺失时显示经过设计的文字/色块占位，不显示破损图片图标。
- 邮件和电话采用原生链接，不引入可能失败的表单提交。
- JavaScript 不可用时不保证动态交互，但核心页面内容仍由构建产物输出并保持可读。

## 验证标准

- 自动化测试验证六个主要模块、四个精选项目、四组专业技能、核心量化数据和联系链接均已渲染。
- 自动化测试验证锚点导航目标存在且标签明确。
- 生产构建命令成功完成且无编译错误。
- 在桌面浏览器预览中检查 1440px 及更宽视口下的版心、首屏高度、卡片布局、文字可读性和视频回退。
- 检查页面无横向溢出，键盘可访问主要链接，减少动态偏好得到响应。

## 后续迭代接口

后续用户提供参考网站、页面截图、真实头像、项目截图与更完整项目说明时，将保留内容数据与组件边界，重点替换视觉变量、排版、媒体资产和局部动效。除非参考设计要求改变信息架构，否则无需重写页面骨架。
