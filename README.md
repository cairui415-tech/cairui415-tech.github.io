# 蔡睿个人作品集

面向互联网公司招聘场景的 React + Vite 单页个人作品集，使用 vinext 和 Sites Vite 插件构建。

## 本地运行

```bash
npm install
npm run dev
```

使用 `npm test` 验证服务端渲染内容，使用 `npm run build` 生成生产构建。

## 媒体来源

Hero 背景视频 `public/hero-loop.mp4` 来自 [MDN Interactive Examples](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4) 的 CC0 示例素材，并在页面中经过模糊、去色、提亮和遮罩处理作为抽象动态纹理。
